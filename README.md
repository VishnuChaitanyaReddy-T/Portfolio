Static portfolio site (HTML, CSS, JavaScript). No build step.

- `index.html` page content
- `style.css` styling
- `script.js` interactive ethanol-water chart in the hero
- `photo.jpg` portrait shown in the About section (converted from HEIC, cropped 4:5)
- `Vishnu_Chaitanya_Reddy_Thadigotla_Resume.pdf` linked by the "Download resume" button

## Publish on GitHub Pages
1. Create a repository, for example `portfolio` (or `VishnuChaitanyaReddy-T.github.io` for a root URL).
2. Upload all files in this folder to the repository root.
3. Go to Settings, then Pages. Under Build and deployment choose "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
4. After a minute the site is live at `https://VishnuChaitanyaReddy-T.github.io/portfolio/`.
